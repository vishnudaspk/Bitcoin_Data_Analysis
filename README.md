# Bitcoin Data Analysis

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://opensource.org/licenses/GPL-3.0)

## Overview

This project performs a comprehensive data analysis on historical Bitcoin price data using Python. The main goal is to explore Bitcoin's price trends, understand its daily price fluctuations, and visualize key patterns over time. The analysis is conducted through a well-documented Jupyter Notebook, providing step-by-step insights into Bitcoin's market behavior.

---

## Features

- **Data Loading and Cleaning:**  
  Import historical Bitcoin price data and prepare it for analysis by cleaning and structuring the dataset into a usable DataFrame.

- **Exploratory Data Analysis (EDA):**  
  Investigate the dataset through statistical summaries and visualizations to reveal underlying trends and anomalies.

- **Price Trend Analysis:**  
  Filter and analyze price movements to detect significant trends and shifts in the Bitcoin market over time.

- **Daily Price Change Computation:**  
  Calculate daily price changes to understand volatility and market dynamics.

- **Visualizations:**  
  Use Matplotlib and Seaborn libraries to create clear and informative charts illustrating Bitcoin's price trajectory and daily changes.

---
